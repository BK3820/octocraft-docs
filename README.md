# OctoCraft documentation

Public documentation for OctoCraft, an approval workspace that turns reviewed requests into GitHub Apps and hands their credentials to a vault.

**Read it:** https://bk3820.github.io/octocraft-docs/

This repository holds only the published page. The OctoCraft source repository is private.

## Updating the page

The site is one self-contained file, `index.html`, with inline CSS, SVG diagrams and JavaScript and no build step. Edit it and push to `main`; GitHub Pages republishes it in about a minute.
